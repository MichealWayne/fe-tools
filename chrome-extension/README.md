# FrontEnd Tools Chrome Plugin

FE-Tools 是一款面向前端开发者的 Chrome 浏览器插件，采用 Vue 3 + TypeScript + Vite 构建，支持 Chrome Manifest V3，并提供中文 / English 双语界面。当前产物版本为 `1.6.0`。

> 本目录是可直接加载的插件产物；源码、构建脚本和版本校验以 [fe-tools-chrome-plugin](https://github.com/MichealWayne/fe-tools-chrome-plugin) 为准。

## 先了解这几个信任边界

- **数据默认留在浏览器本地**：语言、拼音设置、Postman 环境/历史、Codex 额度快照等通过 Chrome `storage` 保存。Codex 功能只保存额度百分比和时间，不保存 ChatGPT 凭据或账户信息。
- **Codex 安装后后台定时检查，用户可关闭**：需要登录 ChatGPT；插件会从 ChatGPT 页面会话读取额度结果，原始 token 不回传到插件界面，也不写入本地存储。额度请求失败时保留最近一次成功结果，并显示更新时间。当前版本可通过 Chrome 通知设置关闭提醒，后台定时检查本身暂未提供独立开关。
- **远程工具目录是补充数据源**：远程目录不可用时，本地内置工具和其他页面仍可打开；请求使用超时和有限重试，避免网络异常长时间卡住面板。
- **跨上下文消息会校验**：弹窗、内容脚本和后台之间使用固定消息契约，并校验消息来源和字段，减少页面脚本注入无效消息的影响。
- **HTML / SVG 预览会先清洗**：Postman 响应、SVG 预览和搜索高亮等动态内容经过转义或 DOMPurify 清洗后才渲染。
- **页面能力需要访问当前网页**：截图和技术栈检测会读取当前活动标签页，内容脚本匹配普通 `http/https` 页面；Chrome 内置页、扩展商店等受浏览器限制的页面无法使用这些能力。

插件仍需要 `activeTab`、`tabs`、`scripting`、`storage`、`downloads`、`contextMenus`、`alarms`、`notifications`、`bookmarks` 等权限，分别用于当前页面分析/截图、设置与缓存、文件保存、右键菜单、Codex 定时检查和书签搜索。当前构建还声明了对网页请求的 `webRequest` 权限以及全网页 host permission；源码中目前未检索到直接调用 `webRequest` 的代码，因此这仍是一个应在后续版本收紧的权限项，发布前需要复核并做回归测试。

## 安装方式

1. 下载或克隆本仓库到本地。
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`。
3. 打开右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择本仓库下的 `chrome-extension/` 目录。
6. 安装完成后，可在浏览器工具栏中固定 FE-Tools 插件图标，方便日常使用。

> 如果更新了本目录下的插件文件，请回到 `chrome://extensions/`，在 FE-Tools 插件卡片上点击刷新按钮重新加载。

### 从源码构建

如需审计代码或自行构建，请进入源码仓库，并使用 Node.js 20+ 与 pnpm：

```sh
pnpm install
pnpm run typecheck
pnpm run check:version
pnpm run lint:check
pnpm run test:run
pnpm run build
```

构建完成后，在 Chrome 的「加载已解压的扩展程序」中选择源码仓库的 `dist/`，不要手动编辑 `dist/` 内的生成文件。

## 使用方式

- **打开工具面板**: 点击浏览器工具栏中的 FE-Tools 图标，即可打开插件主面板。
- **搜索与快捷跳转**: 在首页输入关键词，可搜索工具库、书签，或跳转到 MDN、GitHub、NPM、CanIUse、StackOverflow 等站点。
- **地址栏快捷搜索**: 在 Chrome 地址栏输入 `fe` 后按空格或 Tab，再输入关键词，可使用插件提供的 omnibox 搜索入口。
- **右键菜单**: 在页面中可通过右键菜单使用插件提供的快捷能力，具体菜单项以当前版本展示为准。
- **页面类工具**: 页面截图、技术栈判断等能力会作用于当前活动标签页，首次使用时请按 Chrome 提示授予相关权限。
- **本地设置**: 语言、拼音搜索等偏好会保存在浏览器本地存储中，重新打开插件后仍会保留。
- **Codex 额度**: 需要登录 ChatGPT；可查看 5 小时、每周及其他额度窗口的剩余比例和重置时间，并支持后台刷新、低额度和额度重置通知。

## 核心功能

### 1. 首页搜索

- **多平台搜索**: 支持 MDN、GitHub、NPM、CanIUse、StackOverflow、Google、百度等站点搜索。
- **工具库搜索**: 聚合远程前端工具链接，并按名称、描述、标签匹配。
- **书签搜索**: 读取浏览器书签并在输入关键词时匹配。
- **拼音搜索**: 可在设置中开启，支持中文内容的拼音和首字母匹配。
- **URL 识别**: 输入 `http` 开头的地址时，可直接进入二维码生成。
- **关键词高亮**: 搜索结果会高亮字面命中的关键词。

### 2. 设置窗口

- **语言切换**: 支持中文和英文界面。
- **拼音搜索开关**: 控制首页搜索是否启用拼音匹配。
- **偏好保存**: 设置项会写入本地存储，后续打开保持一致。

### 3. 二维码生成器

- **文本 / URL 转二维码**: 输入内容后生成二维码。
- **当前页面入口**: 可通过 URL 参数携带页面地址生成二维码。
- **SVG 下载**: 支持导出 SVG 矢量文件。
- **PNG 保存提示**: 可通过右键保存二维码图片。

### 4. 图片压缩工具

- **多格式支持**: 支持 JPG、PNG、GIF 等常见图片格式。
- **拖拽上传**: 支持点击选择和拖拽上传。
- **压缩比例**: 可设置 0-1 的压缩比例。
- **Base64 输出**: 输出压缩后图片的 Base64 编码。
- **重置图片**: 可清空当前图片重新选择。

### 5. 色值转换器

- **多格式互转**: 支持 HEX、RGB、HSB、HSL 相互转换。
- **实时预览**: 输入色值后显示颜色效果。
- **格式说明**: 页面提供 RGB、HEX、HSB、HSL 的简要说明。

### 6. API 测试工具

- **HTTP 方法**: 支持 GET、POST、PUT、DELETE、PATCH、HEAD、OPTIONS。
- **请求头编辑**: 支持添加、删除请求头。
- **请求体类型**: 支持 None、JSON、Form Data、x-www-form-urlencoded、Raw。
- **鉴权配置**: 支持无认证、Bearer Token、Basic Auth、API Key，API Key 可放入 Header 或 Query。
- **环境变量**: 支持创建环境、管理变量、导入导出环境配置。
- **响应查看**: 展示响应体、响应头、Cookies、状态码、耗时和大小。
- **历史记录**: 保存请求历史，支持复用和清空。
- **历史筛选**: 可按请求方法、状态和关键词筛选历史。
- **响应搜索**: 可在响应内容中搜索关键词。
- **取消与超时**: 支持取消进行中的请求，并对请求设置超时边界。
- **导入导出**: 支持请求配置 JSON 和 cURL 导入 / 导出。
- **敏感信息保护**: 请求历史展示默认对 Authorization、Cookie 等敏感请求头脱敏；POST 请求默认不自动重试。

### 7. 语言翻译

- **外部翻译入口**: 首页提供有道翻译快捷入口。

### 8. 单位换算器

- **CSS 单位互转**: 支持 px、rem、vw 换算。
- **rem 比例**: 默认 `1rem = 75px`，可自定义。
- **精度设置**: 可设置结果保留的小数位数。

### 9. Moo-CSS 查询

- **模块搜索**: 查询 Moo-CSS 模块和样式属性。
- **文档跳转**: 可跳转到相关文档页面。

### 10. 正则表达式工具

- **常用正则**: 收录前端开发常用正则表达式。
- **关键词筛选**: 按名称或分类筛选。
- **实时测试**: 输入测试字符串后验证匹配结果。

### 11. 工具方法查询

- **函数检索**: 搜索常用 JavaScript 工具函数。
- **模块索引**: 按模块列表定位工具库文档。

### 12. JSON 转换与格式化

- **JS / JSON 互转**: 支持 JavaScript 对象字面量与 JSON 双向转换。
- **格式化输出**: 支持默认、压缩、2 空格、4 空格缩进。
- **复制输出**: 一键复制转换结果。
- **错误提示**: 转换失败时显示具体错误信息。

### 13. SVG 编辑器

- **代码输入 / 上传**: 支持粘贴 SVG 代码或上传 SVG 文件。
- **在线优化**: 支持移除注释、空属性、空文本、隐藏元素、元数据、未使用命名空间，清理 ID，优化颜色值等。
- **预览与统计**: 展示 SVG 预览、原始大小、优化后大小和压缩比例。
- **复制 / 下载**: 支持复制优化结果和下载 SVG 文件。

### 14. 日期与时间戳转换

- **多格式输入**: 支持 Unix 时间戳、ISO、本地时间、自定义格式。
- **多时区输出**: 支持中国、日本、英国、中欧、美国东部、美国太平洋、UTC 等时区。
- **常用结果**: 输出秒 / 毫秒时间戳、ISO、本地时间、UTC、相对时间。
- **日期计算**: 支持按秒、分、时、日、周、月、年添加或减去时间。

### 15. Linux 命令查询

- **命令搜索**: 按命令名筛选。
- **详情查看**: 展示语法、示例和常用选项。
- **快捷命令**: 提供常用命令快速入口。

### 16. 页面截图

- **整页截图**: 自动滚动并拼接完整页面截图。
- **节点截图**: 在当前页面选择元素并截图。
- **预览与保存**: 截图后可预览、重新截图并保存到本地。

### 17. 技术栈判断

- **当前页面分析**: 分析活动标签页的技术栈特征。
- **多信号检测**: 综合脚本、资源、DOM、全局变量、运行时和 meta 等信号。
- **支持类别**: 覆盖 Vue、React、Angular、Next.js、Nuxt、Svelte、Vite、Webpack 及 axios、Pinia、Redux、Zustand、TanStack Query 等常见库。
- **版本与证据**: 尽可能展示版本、命中的信号和检测依据。
- **置信度展示**: 按高 / 中 / 低置信度展示命中结果，单个弱信号不会直接等同于确定使用。

### 18. Codex 额度监控

- **额度窗口**: 查看 ChatGPT Codex 的剩余比例和重置时间。
- **缓存与刷新**: 使用本地快照减少重复请求，支持手动刷新和后台定时刷新。
- **通知**: 额度低于阈值或重置后可通过 Chrome 通知提醒。
- **隐私边界**: 需要 ChatGPT 登录态；只缓存额度百分比和时间，不保存 ChatGPT 凭据或账户信息。网络异常时保留最近一次成功结果，并标注更新时间。

## 稳定性与已知限制

- 远程工具目录、翻译等外部服务依赖网络；远程目录失败不会阻塞本地工具入口，单个功能会显示错误或重试入口。
- 页面截图需要读取和滚动当前页面，跨域 iframe、浏览器内部页面和受限页面可能无法完整捕获。
- 技术栈检测是基于页面信号的推断，版本和置信度应作为辅助信息，不应替代项目源码或构建配置。
- Codex 额度依赖 ChatGPT 当前登录态和接口可用性；服务端接口或登录状态变化可能导致暂时无法读取。
- 本目录采用手动加载未打包扩展的方式分发；正式使用前建议从源码构建，并检查权限、版本和测试结果。

- 生成文件：源码仓库的 `dist/` 是构建产物，功能修改应在 `src/` 或 `public/` 中完成后重新构建。
